# Org Profile

The `.github` repo. Its `profile/README.md` is what GitHub renders on [github.com/Stone-Arch-Silicon](https://github.com/Stone-Arch-Silicon) — the first thing any visitor sees.

**Stage:** live and current. Content only; no code, no workflows, no Pages.

## Contents

The entire repository:

```text
README.md            two lines: title and the org description
profile/README.md    the rendered org profile
```

The profile holds a tagline, three top links (club website, Start ASIC 101, project and contributor guide), a "Find your starting point" table covering all six public repos, and a pointer to the [ASIC Network](https://github.com/ASIC-Network).

## Why it matters more than its size suggests

It is the **highest-traffic page in the org** and the only one a stranger sees before deciding whether to look further. It is also a hand-maintained mirror of the club website's README.

## Start here

Edit `profile/README.md`. GitHub re-renders it immediately — no build, no deploy.

## What is missing

It has no stated gaps of its own; it documents other projects' gaps, describing ASIC 101 as having ongoing course validation and the posit work as currently a documentation project.

Its real risk is **drift**: nothing automates the sync with the club website's README or this site. When you change a project's stage, change it here too. See [the drift problem](page_13.md).
