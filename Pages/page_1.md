# What Stone Arch Silicon is building

Stone Arch Silicon is a student semiconductor-design community at the **University of Minnesota**. We take ECE coursework and turn it into projects that can be built, verified, explained, and handed to another engineer.

This site is the project directory: one page per project, what it is, what stage it is actually at, and where its code lives.

## The eight repositories

| Project | In one line | Track |
| --- | --- | --- |
| ASIC 101 | 25-lesson course: 8-bit ALU from RTL to GDSII | Curriculum |
| ASIC Tutor | Interactive exercise runner for those lessons | Curriculum |
| ASIC Docs | The reference book, built with mdBook | Documentation |
| ASIC Docs Theme | Shared mdBook styling and HDL highlighting | Documentation |
| Systolic Matrix Multiplier | 2x2 systolic array in SystemVerilog | Hardware |
| 8-Bit Posit | Posit arithmetic research for UMN UROP | Research |
| Club Website | The public front door and project list | Infrastructure |
| Org Profile | The org landing README on GitHub | Infrastructure |

## How to read this site

Each track gets an overview page, then one page per project. Project pages all answer the same five questions:

```text
what it is
what stage it is at
what is in the repo
where to start
what is missing
```

## Where to go first

- New to the club: [ASIC 101](page_5.md), start at lesson 1.
- Want to write docs: [ASIC Docs](page_8.md).
